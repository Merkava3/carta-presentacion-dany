# 💻 Tecno Express - Tarjeta de Presentación Digital

Sitio web interactivo estilo "Link in Bio" / carta de presentación digital para **Tecno Express - Soluciones Tecnológicas Integrales**, liderado por **Danis Daniel Fuentes Julio**.

## 📌 Características
- 🎨 Diseño Bento Grid moderno y adaptable (responsive).
- 🌓 Conmutador de modo claro / modo oscuro con persistencia.
- 🖼 Galería interactiva de trabajos realizados con visor GLightbox.
- 📍 Integración directa con Google Maps y datos de contacto (WhatsApp, redes sociales).
- ⚡ Desarrollado con HTML5, CSS3 y JavaScript nativo.

## 🛠 Tecnologías Utilizadas
- **HTML5** & **CSS3**
- **JavaScript (Vanilla)**
- **GLightbox** para la visualización de imágenes
